## 符号与卡面格式

| 符号 | 用法 | 示例 |
| --- | --- | --- |
| `【 】` | 卡牌名 | `【杀】`、`【无懈可击】` |
| `〖 〗` | 技能名 | `〖观星〗` |
| `“X”` | 标记名（首次出现须定义） | `置于武将牌上（称为“权”）` |
| `①②` | 同一技能内多效果拆分 | `①当你受到……<br/>②你的手牌上限……` |
| `／` 或 `/` | 同构成分简写 | `红/黑`、`使用或打出` |
| `▶` | 消耗与效果分隔（一个技能最多一个消耗） | `你可弃置一张牌▶你摸等量的牌。` |

FreeKill 翻译表 `:[技能]` 的适配要点：

- Lua 字符串用双引号包住描述时，标记引号写中文引号 `“X”`（或转义 `\"X\"`），避免破坏 Lua 语法
- 多段效果用 `<br/>` 换行，通常加在 `①②` 前
- “锁定技、”“觉醒技，”这类前缀不要手动加粗；用户明确不要前缀时照做

## 标签与句式模板

| 标签 | 含义与措辞要点 | 经典范例 |
| --- | --- | --- |
| **锁定技** | 不存在“不发动”选项；但**发动强制 ≠ 内部分支全强制**，分支是否可选仍由“可”决定 | `锁定技，若你没有手牌，你不是【杀】和【决斗】的合法目标。` |
| **觉醒技** | 满足条件后强制发动并转型 | `觉醒技，准备阶段开始时，若你没有手牌，……你减1点体力上限，获得〖观星〗。` |
| **限定技** | 整局游戏限一次 | `限定技，出牌阶段，你可……` |
| **主公技** | 仅主公拥有，常与势力联动 | `主公技，锁定技，其他吴势力角色对你使用的【桃】回复的体力+1。` |
| **状态技** | 无时机，持续成立 | `锁定技，你至其他角色的距离-1。` |

**“可”字决定可选性**：有消耗的技能，消耗前的“可”决定是否发动；无消耗技能，唯一效果前的“可”决定是否发动。非锁定技全文没有“可”时，必须先向用户确认是强制发动（应标锁定技）还是可选发动（补“可”），不要靠技能名或主题猜测。

## 时机命名

### 阶段时机（五种标准写法）

| 写法 | 精确含义 |
| --- | --- |
| `X阶段开始前` | 该阶段开始前的系统时机（如跳过阶段） |
| `X阶段开始时` | 阶段刚开始的瞬间 |
| `X阶段` | **该阶段内的空闲时间点**（主动技用此写法，配“限一次”） |
| `X阶段结束前` | 阶段结束前的系统时机 |
| `X阶段结束时` | 阶段结束的瞬间 |

注意：`出牌阶段限一次` 是固定搭配，次数限制挂在时机后，不塞进效果里。

### 事件时机与视角

| 句式 | 视角／结算点 | 对应 Lua 方向 |
| --- | --- | --- |
| `当你使用【杀】选择目标后` | 使用者视角 | `fk.TargetSpecifying` / `fk.TargetSpecified` |
| `当你成为【杀】的目标时` | 目标视角（不写“当【杀】指定目标后”） | `fk.TargetConfirming` / `fk.TargetConfirmed` |
| `当你受到1点伤害时` vs `后` | `时` = 扣血前；`后` = 扣血后 | `fk.DamageInflicted` vs `fk.Damaged` |
| `当你造成伤害时` vs `后` | `时` = 结算中；`后` = 造成后 | `fk.DamageCaused` vs `fk.Damage` |
| `判定结果确定前` vs `后` | 改判用`前`，取结果用`后` | `fk.AskForRetrial` vs `fk.FinishJudge` |
| `当此牌置入弃牌堆后` | 牌离开或进入弃牌堆 | `fk.AfterCardsMove` |

DIY 卡面面向玩家，回合级结束时机默认使用游戏内常见的 `每回合结束时`／`一名角色的结束阶段` 等写法；只有在需要精确区分同一时点内多个效果的先后顺序时，再补边界备注。

## 操作动词精确定义

以下动词直接决定 Lua 实现调用哪套 API 与谁来选牌，编写时不能混用：

| 动词 | 精确含义（谁选／怎么结算） | 常见误用与改法 |
| --- | --- | --- |
| `弃置` | 角色弃置**自己区域里**的牌（本人选牌） | 写“你弃置B的一张牌”时，选牌权在**你**；想让B自己选，改写“**你令B弃置一张牌**” |
| `令……弃置` | A 令 B 弃置 ⇒ **B** 选牌 | 同上，主语和选牌方要一致 |
| `获得` vs `得到` | `获得` = 主动操作；`得到` = 结果性陈述 | 主动摸／拿写“获得” |
| `交给` | 把**自己拥有**的牌置入目标区域 | “将其一张牌交给另一名角色”有误（牌不是你的）⇒ 写“令其将一张牌交给……”或“你获得其一张牌并交给……” |
| `观看` vs `展示` vs `亮出` | `观看` = 仅查看不公开；`展示` = 对全场公开；`亮出` = 牌面朝上置放 | 三者不互换 |
| `重铸` | 固定组合 = 将此牌置入弃牌堆 + 摸一张牌 | 有额外附加效果时不要借用“重铸” |
| `造成伤害` vs `失去体力` | `失去体力`无来源、不触发伤害事件与奖惩 | 想“掉血但不算伤害／不触发卖血”时写`失去X点体力`，勿写“造成伤害” |
| `减1点体力上限` | 修改 `maxHp`，不同于失去体力 | 不能写成“失去1点体力上限” |
| `无效` vs `取消` vs `防止` | `无效` = 效果不生效；`取消` = 终止对某目标的使用；`防止` = 拦截伤害数值 | “防止此次伤害” ≠ “令此【杀】无效” |
| `视为使用／打出` | 按转化牌结算；不产生实体牌使用计数时须写明 | 与`使用／打出`实体牌区分 |

## 人称、合法性、数值与存续区间

- **人称指代**：`"你"` 恒指当前技能拥有者；技能可能转手时，需要原主人收回或结算的句子直接写武将名（见 [技能形态](skill-mechanics.md#技能转手后的措辞)）。同一句存在两个候选角色时，不用 `"其"`，改写 `"该角色"`／`"此角色"`；承前分句换了主语时必须补出新主语。
- **合法性表述**：受距离／能力约束选目标写 `"能……的"`（例如“能使用【决斗】的角色”）；受规则目标限制写 `"……的合法目标"`（例如“此【杀】的合法目标”）。
- **距离与数值下限**：
  - 距离、攻击范围下限为 1，手牌上限下限为 0
  - `你至其他角色的距离` ≠ `其他角色至你的距离`，单向还是双向必须写明
  - `等量` 必须紧跟前一个非固定数量（如“弃置至少一张牌▶摸等量的牌”）
  - `一半` 建议注明 `一半（向下取整）` 消歧
- **变量 `X` 位置**：单处使用时定义紧跟首次出现，如 `X为“权”数`；多处使用时放在整句末、句号之后统一覆盖，如 `1.……摸X张牌；2.……弃置X张牌。（X为你已损失的体力值）`。
- **存续区间**：临时效果必须写清何时结束（`直到本回合结束`／`直到你的下回合开始`／`直到你的下回合结束`）；不写存续默认即时效果。

## 常见白话转规范用语

| 常见口语／白话 | 规范卡面用语 |
| --- | --- |
| 空勾玉／掉的血 | `你已损失的体力值`（或 `你的体力上限与体力值之差`） |
| 满血 | `你未受伤`（体力值等于体力上限） |
| 残血／没血了 | `你已受伤`／`你的体力值为1`／`你进入濒死状态时` |
| 掉 1 点血（不算伤害） | `失去1点体力` |
| 打他 1 点伤害 | `对其造成1点伤害`（带属性写 `火焰伤害`／`雷电伤害`） |
| 摸牌阶段多摸 1 张 | `摸牌阶段，你可多摸一张牌`（锁定加 `锁定技，`） |
| 弃牌阶段不弃某类牌 | `你的【……】不计入手牌上限` |
| 拿牌堆顶 3 张看／选 | `你观看牌堆顶的三张牌，然后……` |
| 不足 X 张全弃／全摸 | 简写时补注或用 `至多X张`（明确少于 X 时按实际数量执行） |

## 成文自查清单

写进 `:[技能]` 翻译键前过一遍：

1. 时机写法是否明确且视角正确（`成为目标时` vs `指定目标后`、`伤害时` vs `伤害后`）？
2. 非锁定技的“可”字位置是否正确（可选发动 vs 可选执行）？
3. 同一消耗是否只有一个操作，且消耗与效果区分清楚？
4. 弃置／交给／观看／展示／造成伤害／失去体力等动词的主语和对象是否与 Lua 实现一致？
5. `“你”` 和 `“其”` 在整句里是否唯一无歧义？
6. 变量 `X`、标记 `“名称”` 是否都在本技能内先定义再引用？
7. 距离方向、数值下限、存续区间以及边界情况（无牌可弃、无合法目标、`X = 0`）是否自洽？
8. `:[技能]` 内多段效果是否用 `①②` 和 `<br/>` 分行，且没有自行造词？
